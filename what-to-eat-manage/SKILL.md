# what-to-eat-manage

## 何时使用此 Skill

日常管理能力 - 支持记录食用菜品、删除菜品等日常维护操作。帮助用户管理菜品库的日常使用记录。


## 何时使用此 Skill

当用户意图属于"日常管理"时，调用此 Skill。

**触发条件**:
- 用户记录食用某道菜品（"我吃了红烧肉"、"记录一下吃了麻婆豆腐"）
- 用户删除菜品（"删除番茄炒鸡蛋"、"去掉宫保鸡丁"）
- 用户提到"吃了"、"吃过"、"记录"、"删除"等关键词


## 1. 记录食用菜品

**用户意图**: 用户吃了某道菜，需要更新食用记录

**CLI 命令**:
```bash
bash ../../scripts/manage.sh eat <菜名>
```

**执行步骤**:
1. 从用户输入中提取菜品名称
2. 执行 eat 命令
3. 告知用户更新结果（第几次食用）

**示例对话**:

```
用户: "我吃了红烧肉"
→ 解析: 菜名="红烧肉"
→ 执行: bash ../../scripts/manage.sh eat "红烧肉"
→ 回复: "✅ 已记录「红烧肉」，今天第 3 次食用"

用户: "记录吃了麻婆豆腐"
→ 执行: bash ../../scripts/manage.sh eat "麻婆豆腐"
→ 回复: "✅ 已记录「麻婆豆腐」，今天第 1 次食用"
```

**功能说明**:
- 更新 `lastEaten` 为今天的日期
- 增加 `eatCount` 计数
- 影响推荐算法的轮换优先级（优先推荐未吃或很久没吃的菜）

---


## 2. 删除菜品

**用户意图**: 用户要从菜品库删除某道菜品

**CLI 命令**:
```bash
bash ../../scripts/manage.sh delete <菜名>
```

**执行步骤**:
1. 从用户输入中提取菜品名称
2. 执行 delete 命令
3. 告知用户删除结果

**示例对话**:

```
用户: "删除番茄炒鸡蛋"
→ 执行: bash ../../scripts/manage.sh delete "番茄炒鸡蛋"
→ 回复: "✅ 已删除「番茄炒鸡蛋」"

用户: "去掉宫保鸡丁"
→ 执行: bash ../../scripts/manage.sh delete "宫保鸡丁"
→ 回复: "✅ 已删除「宫保鸡丁」"
```

**注意事项**:
- 删除操作不可恢复
- 删除后不会出现在推荐结果中
- 如果误删，需要手动重新添加

## 常见错误场景

1. **菜品不存在**
   ```
   用户: "我吃了佛跳墙"
   → 执行: bash ../../scripts/manage.sh eat "佛跳墙"
   → 错误: "❌ 未找到菜品「佛跳墙」"
   → 回复: "这道菜还没添加到菜品库，要不要添加？"
   ```

2. **菜品名不匹配**
   ```
   用户: "我吃了麻婆豆付"
   → 执行: bash ../../scripts/manage.sh eat "麻婆豆付"
   → 错误: "❌ 未找到菜品「麻婆豆付」"
   → 回复: "是不是「麻婆豆腐」？请检查菜品名称"
   ```

3. **删除重要菜品**
   ```
   用户: "删除麻婆豆腐"
   → 执行: bash ../../scripts/manage.sh delete "麻婆豆腐"
   → 回复: "⚠️  确认要删除「麻婆豆腐」吗？\n   删除后无法恢复，需要重新添加。\n   如果要删除，请再说一次。"
   ```


## 菜品名称提取

从用户输入中智能提取菜品名称：

| 用户输入 | 提取结果 | 说明 |
|---------|---------|------|
| "我吃了红烧肉" | 红烧肉 | "吃了" + 菜品名 |
| "记录吃了番茄炒蛋" | 番茄炒蛋 | "记录吃了" + 菜品名 |
| "吃过宫保鸡丁" | 宫保鸡丁 | "吃过" + 菜品名 |
| "删除水煮鱼" | 水煮鱼 | "删除" + 菜品名 |
| "去掉糖醋排骨" | 糖醋排骨 | "去掉" + 菜品名 |


## 相似名称匹配

如果精确匹配失败，尝试模糊匹配：

```
用户: "我吃了麻婆豆付"
→ 精确匹配失败
→ 模糊匹配: "麻婆豆腐" (相似度 90%)
→ 询问: "你是不是想说「麻婆豆腐」？"
```


## 注意事项

- **记录食用不影响推荐结果**：只是更新 `lastEaten` 和 `eatCount`，不会从菜品库移除
- **删除操作需谨慎**：建议在删除前确认，避免误删
- **名称精确匹配**：需要用户提供准确的菜品名称，不支持模糊删除
- **食用记录可多次**：同一天可以多次记录同一道菜


## 注意事项

- **自包含部署包**：本 Skill 已包含完整的运行时脚本
- **路径引用**：使用相对路径引用脚本（`../../scripts/`）
- **数据文件**：首次使用需要复制 `data/example.json` 到 `data/dishes.json`
